
# Interactive Dashboard

A responsive, accessible analytics dashboard built with
HTML, CSS, JavaScript, and SVG.

## Overview

This project demonstrates frontend development,
interactive data visualization, responsive design,
and accessibility best practices.

Users can explore monthly sales and website visits
through an interactive SVG bar chart.

## Features

- Interactive 12-month SVG bar chart
- Switch between Sales and Website Visits
- Dynamic summary statistics
- Animated chart bars
- Mouse, keyboard, and touch interactions
- Interactive data tooltips
- Chart gridlines, labels, and legend
- Light and dark themes
- Theme preferences saved with localStorage
- Responsive layouts for desktop and mobile
- Reduced-motion support
- Accessible chart descriptions and focus indicators

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- SVG
- CSS Grid and Flexbox
- Web Storage API

## Accessibility

The dashboard includes:

- Keyboard-accessible chart bars
- Visible keyboard focus indicators
- Accessible labels for chart data
- Reduced-motion support
- Responsive layout and readable typography

## Getting Started

1. Download or clone the repository.
2. Open index.html in a web browser.
3. Use the buttons to switch datasets.
4. Explore the chart and theme options.

No additional dependencies are required.

## Data

The dashboard uses sample data for demonstration
purposes. It does not connect to a live analytics API.
